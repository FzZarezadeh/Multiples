🔁 Recursive Multiples Printer – C# Console App

A lightweight console application written in C# that recursively prints descending multiples of 3 starting from a user-defined number. The program uses color-coded output to indicate completion and demonstrates basic recursion, input handling, and console styling.

---

📦 Features

- Recursive Logic:
  - Prints numbers divisible by 3 in descending order.
  - Decrements by 7 on each recursive call.
  - Stops when the number is less than 3.

- User Input:
  - Prompts the user to enter a starting number.
  - Begins recursion from n - 1.

- Console Styling:
  - Uses red text to indicate the termination message ("end").

---

🛠 Technologies Used

- Language: C#
- Platform: .NET Console Application
- IDE: Visual Studio or any C#-compatible editor

---

🚀 How to Run

1. Clone or download the repository.
2. Open the solution in Visual Studio.
3. Build and run the project.
4. Enter a number when prompted.
5. View the output of descending multiples of 3.
